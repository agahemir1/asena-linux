<kbd>Super</kbd>, çoğu klavyede Windows logolu tuştur.

| Kısayol | İş |
| --- | --- |
| <kbd>Super</kbd> + <kbd>Boşluk</kbd> | Başlat menüsünü aç ya da kapat |
| <kbd>Super</kbd> + <kbd>A</kbd> | Denetim merkezi |
| <kbd>Super</kbd> + <kbd>N</kbd> | Bildirimler ve takvim |
| <kbd>Super</kbd> + <kbd>Enter</kbd> | Uçbirim (Foot) |
| <kbd>Alt</kbd> + <kbd>Tab</kbd> | Sonraki pencere |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>Tab</kbd> | Önceki pencere |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> | Klavye düzenini değiştir |
| <kbd>Print</kbd> | Ekranın görüntüsünü kaydet |
| Ses tuşları | Sesi aç, kıs, kapat; mikrofonu kapat |
| Parlaklık tuşları | Ekran parlaklığı |

## TR-F klavyede harfli kısayollar

Wayfire kısayolları harfe değil, klavyedeki fiziksel tuşa bakar. Bu yüzden TR-F klavyede <kbd>Super</kbd> + <kbd>A</kbd> eskiden başka bir tuşa düşüyordu.

Asena harfli kısayolları, ilk klavye düzeninizde o harfi yazan tuşa çevirir. TR-F klavyede <kbd>Super</kbd> + <kbd>A</kbd>, üzerinde A yazan tuştur. <kbd>Enter</kbd>, <kbd>Boşluk</kbd>, <kbd>Print</kbd> ve ortam tuşları düzenden bağımsızdır.

## Menüde gezinmek

Menünün arama kutusuna yazıp <kbd>Enter</kbd>’a basınca ilk sonuç açılır; ok tuşlarıyla sonuç listesine geçersiniz. <kbd>Esc</kbd> menüyü kapatır.
