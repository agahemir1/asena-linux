## What Asena is

Asena Linux is a distribution built on Debian 13, and its desktop. The desktop is our own shell, written in Rust and GTK4/libadwaita and running on the Wayfire compositor: a bottom panel, a start menu, a control center, a notification panel, and the lock and login screens.

Asena is made for:

- people coming from Windows who want the layout they know
- Turkish speakers, students and schools
- anyone who wants a plain, fast and consistent desktop

## Where it stands today

Asena is in development and there is no release to download yet. The desktop, Settings and twelve apps run in the development virtual machine. The live ISO is scaffolded, but the first ISO has not been built. The current state is on the [Download](/en/download/) page, with details in [News](/en/news/).
