<kbd>Super</kbd> is the key with the Windows logo on most keyboards.

| Shortcut | Does |
| --- | --- |
| <kbd>Super</kbd> + <kbd>Space</kbd> | Open or close the start menu |
| <kbd>Super</kbd> + <kbd>A</kbd> | Control center |
| <kbd>Super</kbd> + <kbd>N</kbd> | Notifications and calendar |
| <kbd>Super</kbd> + <kbd>Enter</kbd> | Terminal (Foot) |
| <kbd>Alt</kbd> + <kbd>Tab</kbd> | Next window |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>Tab</kbd> | Previous window |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> | Switch keyboard layout |
| <kbd>Print</kbd> | Save a screenshot of the screen |
| Volume keys | Volume up, down, mute; microphone mute |
| Brightness keys | Screen brightness |

## Letter shortcuts on a Turkish F keyboard

Wayfire matches shortcuts by physical key, not by letter, so on a Turkish F keyboard <kbd>Super</kbd> + <kbd>A</kbd> used to land on a different key.

Asena now maps letter shortcuts to whichever key types that letter in your first keyboard layout. On Turkish F, <kbd>Super</kbd> + <kbd>A</kbd> is the key labeled A. <kbd>Enter</kbd>, <kbd>Space</kbd>, <kbd>Print</kbd> and the media keys do not depend on the layout.

## Moving around the menu

Type in the menu’s search box and press <kbd>Enter</kbd> to open the first result; the arrow keys move into the result list. <kbd>Esc</kbd> closes the menu.
